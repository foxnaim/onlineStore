## About

A full-featured online marketplace built with React and Vite. Browse products, manage inventory, and handle orders with a clean, modern interface.

## Features

- 🛍️ **Product Management** — CRUD operations for products
- 🔍 **Search & Filter** — Find products quickly
- 🛒 **Shopping Cart** — Full cart functionality
- 📱 **Responsive Design** — Works on all devices
- ⚡ **Vite-powered** — Lightning fast development

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Framework | React + Vite |
| Language | JavaScript |
| Styling | Tailwind CSS |

## Getting Started

```bash
git clone https://github.com/foxnaim/onlineStore.git
cd onlineStore
yarn install
yarn dev
```
